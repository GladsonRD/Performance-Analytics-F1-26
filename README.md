# Performance Analytics — F1 26

Grava a telemetria UDP do F1 26 no PC e, ao fim de cada classificação ou corrida, gera um relatório HTML
com a análise da sessão: resumo com dicas de pilotagem e acerto, tempos e setores, análise de volta com
telemetria e mapa, traçado e replay, ritmo de corrida, estratégia, pneus, energia e eventos.

## Como instalar

1. Clique no botão verde **Code → Download ZIP** e extraia o arquivo.
2. Abra a pasta **f1_telemetria** e dê dois cliques em **INSTALAR.vbs**.
   Ele instala o Python se precisar e cria o atalho **Telemetria F1 26** na Área de Trabalho.
3. No jogo, ative a telemetria UDP (porta 20777, formato 2026). Os detalhes estão no
   [LEIA-ME](f1_telemetria/LEIA-ME.md).

## Como atualizar

Abra o programa pelo atalho e clique em **Atualizar**. A janela avisa quando há versão nova.
